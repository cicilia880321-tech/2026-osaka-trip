# 2026 京都・大阪賞楓行

2026/11/28–12/02，雙人五日行程。繁體中文、手機優先的純 HTML / CSS / JavaScript 靜態網站，無套件依賴、登入或 API Key。

## 開發與資料編輯

在儲存庫根目錄執行 `python3 -m http.server 8000`，以本機瀏覽器開啟檢查。編輯 `index.html`（頁面結構）、`style.css`（樣式）與 `app.js`（行程、注意事項及預設預算）。所有行程顯示為固定日本當地時間 Asia/Tokyo，不依瀏覽器時區轉換。桃園起降時間依提供行程照錄，頁面提醒與機票的當地時間再次核對。交通、2026 秋季開放資訊及待確認餐廳不是即時查詢結果。

`days` 存放完整行程及 Google Maps 搜尋詞；未確認的餐廳分店不可視為已確認地址。`expenseDefaults` 存放預設雙人日幣金額。費用收在對應行程的右側，點金額展開編輯；`costSlots` 綁定行程與費用，保持每筆只出現一次。每日及全程合計列在行程下方；跨日費用保留未分配。購物清單採列式編輯，備註與刪除收在「更多」，備份操作亦預設收合。既有 localStorage 與 JSON 備份格式維持相容。已知金額、估算、待填與付款狀態分開紀錄。新填金額預設歸為估算，核對來源後可改為已知金額。單人只將顯示除以二，避免重複計算。大阪飯店 ¥42,161 為扣款提醒，不是第二筆支出。三晚京都住宿及機票列為未分配，避免錯誤拆分每日花費。

## 儲存與備份

預算、購物清單、幣別、人數及匯率儲存於瀏覽器 localStorage（鍵名 `osaka-autumn-2026-v1`）。不會自動跨裝置同步，也沒有多人即時共同編輯。清除網站資料或使用不同瀏覽器會影響本機內容。

使用「匯出 JSON 備份」下載全部可編輯資料；在另一裝置開啟網站，以「匯入 JSON 備份」還原。匯入會經格式檢查與確認後取代現有資料。匯入上限 2 MB、500 項商品。修改預設資料不會覆寫使用者既有 localStorage；如需採用新版預設，請先匯出備份，再清除此網站儲存資料。

公開網站與 Git 歷史不得包含訂位編號、驗證碼、QR Code、護照、電話、Email、信用卡或私人管理訂單網址。本機備註與備份也請避免放入上述資訊。

## GitHub Pages

入口 `index.html` 位於根目錄，使用相對路徑載入資源，適用 GitHub Pages 專案網站。

在 Repository **Settings → Pages → Build and deployment** 選擇 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/(root)**，按 Save。預期網址為 https://cicilia880321-tech.github.io/2026-osaka-trip/ 。此網址需等待 Pages 實際部署完成才可使用。

`.nojekyll` 讓 GitHub Pages 直接發佈靜態檔案。後續推送 main 將觸發部署；以 Pages 設定及部署狀態確認是否成功，不需要額外建置命令。
